# Site Movelaria Ret

## Sobre o projeto
Desenvolvimento do site institucional da Movelaria Ret, apresentando os serviços, projetos e soluções em móveis planejados.

## Objetivos
- Apresentar a empresa e seus diferenciais.
- Exibir projetos e ambientes planejados.
- Facilitar o contato com clientes.
- Proporcionar uma experiência moderna e responsiva.

## Tecnologias
- HTML
- CSS
- JavaScript
- Design responsivo
